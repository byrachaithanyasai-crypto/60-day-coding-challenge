\## How AI Was Used



AI assistance was used during the development of this project for:



\- Debugging and resolving code and CSS errors.

\- Improving responsive layouts and UI styling.

\- Reviewing typography, colors, spacing, cards, navigation, and dashboard sections.

\- Troubleshooting Git and GitHub configuration.

\- Assisting with GitHub commits and pushes.

\- Assisting with Vercel deployment.

\- Preparing the project for submission.
